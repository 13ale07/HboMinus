# HBO Minus - Clon de HBO Max

## Plataforma Clonada
Hicimos un clon visual de la interfaz de **HBO Max** para practicar diseño web y trabajo en equipo.

## Componentes de Bootstrap Utilizados
- **Grid System (`row-cols`):** Para acomodar los elementos en filas y columnas según el tamaño de la pantalla.
- **Cards (`card`, `card-body`, `card-img-top`):** Para mostrar la información y la imagen de cada película.
- **Containers y Spacing:** Para centrar el contenido y darle espacio/márgenes a los elementos.

## Mi parte
- Diseñé y acomodé la sección de **5 tarjetas de películas destacadas**: *Lanterns*, *Stuart Fails to Save the Universe*, *Mortal Kombat*, *Five Nights at Freddy's 2* y *Bugonia*.
- Agregué la clase `row-cols-lg-5` para que las 5 películas se muestren en una sola fila horizontal cuando se ve en computadoras.
- Ajusté los colores en el archivo CSS (`.hbo-card`) para que coincidieran con el tema oscuro de la plataforma.
