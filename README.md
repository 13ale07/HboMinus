# Plataforma de Películas

##  Descripción

Este proyecto fue creado como una práctica de desarrollo web, inspirado en el diseño y funcionamiento de plataformas de streaming como **HBO Max**.

La página permite visualizar una colección de películas y explorar diferentes opciones de entretenimiento desde distintos dispositivos, como computadora, tableto televisor.

 ¡Disfruta de tus películas favoritas en cualquier lugar y comparte la experiencia con tu familia y amigos!

##  Características

-  Visualización de películas.
-  Exploración de contenido.
-  Diseño pensado para diferentes dispositivos.
-  Sección para registro de usuarios.
-  Interfaz inspirada en plataformas de streaming.
-  Organización del contenido mediante tarjetas.
-  Proyecto desarrollado como práctica de HTML y CSS.

##  Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap

##  Objetivo del proyecto

El objetivo principal de este proyecto fue poner en práctica los conocimientos adquiridos durante el curso, especialmente en la creación de páginas web, estructuración de contenido, diseño de interfaces y utilización de componentes de Bootstrap

# HBO Minus - Clon de HBO Max

## Plataforma Clonada
Hicimos un clon visual de la interfaz de **HBO Max** para practicar diseño web y trabajo en equipo.

## Componentes de Bootstrap Utilizados
- **Grid System (`row-cols`):** Para acomodar los elementos en filas y columnas según el tamaño de la pantalla.
- **Cards (`card`, `card-body`, `card-img-top`):** Para mostrar la información y la imagen de cada película.
- **Containers y Spacing:** Para centrar el contenido y darle espacio/márgenes a los elementos.


- Diseñé y acomodé la sección de **5 tarjetas de películas destacadas**: *Lanterns*, *Stuart Fails to Save the Universe*, *Mortal Kombat*, *Five Nights at Freddy's 2* y *Bugonia*.
- Agregué la clase `row-cols-lg-5` para que las 5 películas se muestren en una sola fila horizontal cuando se ve en computadoras.
- Ajusté los colores en el archivo CSS (`.hbo-card`) para que coincidieran con el tema oscuro de la plataforma.
